RADE

Getting the newest script.

Deploy and test applications on a locked-down work computer from one pasted PowerShell window: checks, files, steps and a results e-mail. RADE checks the computer first, saves the application's files, guides you through each step, and keeps a record of the install. After the install, the application works without RADE.

Checks first:
checks the computer and your site rights before any step; a failed check stops the install.
NIPR only:
runs only where the computer's full name holds the NIPR domain; elsewhere it stops before it writes a file.
Credentials:
CAC sign-on in a browser window for each run; nothing is stored.
Access:
only sees what your account can see; only accepts a DAF SharePoint address.
Boundary:
nothing leaves DoD365, except the test-round results e-mail (masked counts, sent by hand) until the test rounds end.
Verifiable:
read the commented code as plain text before you paste it; the window warns when the script does not match its hash.
Accessible:
paste and run via ISE; no code download, no admin rights, no policy change.
Maintenance:
Diagnose, Back up and Restore from the application's card.
Independent:
delete RADE and the application still works.
