## Items

1. **E1 Shortcut** (intro-fulcrum plan step 7). One shortcut for each app: name `<display> - <version>`, icon `RADE\runners\<key>.ico` (16, 32, 48, 256 px, made at run time from the app's PNG logo, else RADE's), target `RADE\runners\<key>.ps1` (the app's last passed deploy paste). The old `RADE.lnk` and `rade-runner.ps1` go to the Recycle Bin when they are RADE's own. Remove RADE removes the runners folder and the app shortcuts. The install card label: "Shortcut in".
2. **E2 Titles.** Window title `RADE - engine-v42 - <round>` (Q1 decides test only or every bundle); the build stays in Details (F2), the log and the report. New optional manifest field `application.displayName` (fallback: the app name); `application.name` stays the install key.
3. **E3 Scale.** Started from Windows PowerShell ISE, RADE writes its own text to a temp file and starts `powershell.exe -NoProfile -STA -WindowStyle Minimized -File` on it (the shortcut's host), then ends in ISE. Fallbacks (logged): execution policy that blocks a local file, no own text, or a child that exits at once: the window runs in ISE as before. `RADE_ISE_CHILD=0` turns it off.
4. **E4 Back up stall.** Back up child: Stop-SignInSize after the sign-in, a SIGNIN line, a site check, stage lines. Parent: live read of the stage lines with a time limit for each stage and a failure that names the stage; an Alt+Tab hint on the Back up card. Not built: -ExecutionPolicy Bypass (DEC 3), the IE question handling (not proven; source not readable).
5. **Release** engine-v42 (ENGINE_RELEASE 42) by release.yml; message to the 90-161.Z session with the tag, the commit and every new text.
