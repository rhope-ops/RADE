# Security

## Report a vulnerability

Use GitHub private vulnerability reporting for this repository: on the repository's Security tab, choose "Report a vulnerability".

- Do not open a public issue for a security problem.
- Do not put government data, site addresses or personal data in a report.

## Scope

The engine in [engine/](engine/), and the build and check scripts in [scripts/](scripts/).

## What RADE never does

See [docs/engine.md](docs/engine.md), sections "RADE and the app" and "Guardrails".

## Supported version

Only the newest engine release tag.
